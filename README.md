I found this beautiful old top-down racer code from RamboFox (late 2000s Newgrounds and GameMaker 6/7/8 era) on my old CDs from my teenagehood, and even back then I fell in love with its quirky drift physics and delta-quarter sprites. They were too complex but I try to somehow understand the code to.
This is my loving refactor: cleaner GML (modern Game Maker Studio 2), delta-based rendering (TODO: delta damages), parent object prep for a better refactor and eventually a Godot port someday, and a lot more readable structure.
